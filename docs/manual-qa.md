# 薯餅桌寵手動驗收

## 視覺

- [ ] 核對既有 81 張與新增 16 張、共 97 張參考照片的視角、姿勢、可見度與清晰度；原始照片保留在本機，不隨發布包提供。
- [ ] 最終圖集為 1536×2288、8×11 格，每格 192×208。
- [ ] 11 個動作列與 16 個追視方向均通過 contact sheet、逐列預覽及方向盲測。
- [ ] 每列對照原照確認棕白分布、背斑、耳朵、腳掌、比例與毛髮一致。
- [ ] 無額外肢體、裁切、場景、文字、道具、綠邊或明顯身分漂移。

## 視窗與互動

- [ ] 視窗透明、無邊框、不出現在工作列且維持最上層。
- [ ] OBS 擷取視窗可透過設定開啟/關閉；視窗標題為「薯餅 OBS 擷取」、不可點擊、無工作列與固定置頂關係。
- [ ] 移動小於等於 6 DIP 是點擊；超過 6 DIP 才拖動。
- [ ] 單擊抬爪，雙擊跳躍；在頭部來回移動觸發摸頭。
- [ ] 拖動期間停止漫遊；放開後記住位置並恢復原狀態。
- [ ] 靜止時 16 方向追視游標；游標靠近時可呼吸、眨眼或理毛。
- [ ] 坐姿看向正左與正右時身體大小一致；連續繞行游標時沒有忽大忽小。
- [ ] 觸發摸頭時維持相近的坐姿尺寸與腳底位置，不會突然放大或上下跳動。
- [ ] 觸發舔毛時維持與待機／追視相近的尺寸，六格腳底都固定在共同基準線，不會突然放大或下沉。
- [ ] 切換 75%、100% 與 150% 時，寵物全身與透明視窗等比例縮放，不是把原尺寸圖片裁切。

## 漫遊、螢幕與 DPI

- [ ] 關閉漫遊後不再自行位移，但拖動與互動仍正常。
- [ ] 「目前螢幕」不離開當前工作區；「所有螢幕」可跨螢幕且避開工作列。
- [ ] 「所有螢幕」可直接把寵物拖過螢幕邊界；放開後完整留在游標所在螢幕，且不會被舊漫遊目標拉回。
- [ ] 快速模式或畫面短暫卡頓時不會越過目標後持續撞牆；若 250 ms 完全沒有位移，會停止本次路徑並重新選點。
- [ ] 測試單螢幕、負座標排列、不同工作列位置與 100%、125%、150%、200% DPI。
- [ ] 拔除螢幕、改解析度或 DPI 後，寵物自動回到可見工作區。
- [ ] OBS 擷取視窗可選 1280x720、1920x1080、2560x1440、3840x2160 四種尺寸，非合法值回退 1920x1080。
- [ ] OBS 模式下觀察 `薯餅 OBS 擷取`：薯餅於畫布內行走，停留時 row0、移動時 row1/row2，且每次移動目標不會超出畫布邊界且保留安全邊距。
- [ ] OBS 擷取視窗 HWND 保持固定，畫布內 X/Y 位置持續變化；漫遊開關、慢／正常／快三段速度與到點後 1–3.5 秒停留有效。
- [ ] 100%、125%、150%、200% 顯示 DPI 下，OBS 來源仍是所選 physical-pixel 解析度，角色 100% 時維持 192×208 source pixels。
- [ ] 一般桌寵隱藏後 OBS 擷取仍持續；關閉 OBS 擷取或退出程式後，擷取視窗與計時器確實關閉。

## 設定、系統匣與發佈

- [ ] 系統匣可顯示/隱藏、切換漫遊與滑鼠穿透、開啟設定、回主螢幕及退出。
- [ ] 在寵物本體按右鍵會顯示與系統匣相同的選單。
- [ ] 「所有螢幕」模式走到工作區邊界後，會從目標螢幕對應邊緣繼續，不會在原邊界踏步。
- [ ] 開啟滑鼠穿透後仍可由系統匣關閉。
- [ ] 漫遊範圍、速度、75%–150% 大小、OBS 擷取開關／解析度、穿透、開機啟動、最後螢幕與位置可保存。
- [ ] 破損設定或無效位置會安全復原，不使程式無法啟動。
- [ ] Release 測試通過（目前 205 項），`win-x64` 自包含單檔可攜版在乾淨環境啟動。

## 餵食（v1.2.0）

- [ ] 右鍵寵物與系統匣「餵食薯餅」均提供種子棒、花椰菜與小白菜選項，顯示文字正確。
- [ ] 餵食期間漫遊停止，拖曳、單擊、雙擊、摸頭與其他左鍵反應不能覆寫餵食序列。
- [ ] 專用寫實影格維持雙爪—食物—嘴部接觸，完成顯示「吃飽了！」並播放 HappyJump；完成後可恢復拖曳與漫遊。
- [ ] 3 秒冷卻有效；冷卻中不能重複餵食，`TotalFeedCount` 每次完成只增加一次。
- [ ] `TotalFeedCount`、`LastFedUtc`、`LastFoodType` 正確保存；schema 7 設定相容與舊欄位預設正確。
- [ ] click-through 開啟時仍可從系統匣餵食。
- [ ] 75%、100%、150% 縮放及單／多螢幕下，種子棒、花椰菜與小白菜六格進食影格均完整等比例顯示，腳底不跳位且食物維持在雙爪與嘴部之間。
- [ ] 一般與修長模式共 32 格走路維持前一版步態與大小，僅腳底對齊微調；人工需確認無尺寸跳變、裁切或漂移。
- [ ] 透明桌寵視窗與 OBS 擷取視窗的實際視覺操作需在實機人工驗收。
