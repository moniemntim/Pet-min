# 薯餅桌寵手動驗收

## 視覺

- [ ] `pet-art/references/reference_catalog.csv` 有 81 筆且每筆皆有視角、姿勢、可見度與清晰度。
- [ ] 最終圖集為 1536×2288、8×11 格，每格 192×208。
- [ ] 9 個標準動作列與 16 個追視方向均通過 contact sheet、逐列預覽及方向盲測。
- [ ] 每列對照原照確認棕白分布、背斑、耳朵、腳掌、比例與毛髮一致。
- [ ] 無額外肢體、裁切、場景、文字、道具、綠邊或明顯身分漂移。

## 視窗與互動

- [ ] 視窗透明、無邊框、不出現在工作列且維持最上層。
- [ ] 移動小於等於 6 DIP 是點擊；超過 6 DIP 才拖動。
- [ ] 單擊抬爪，雙擊跳躍；在頭部來回移動觸發摸頭。
- [ ] 拖動期間停止漫遊；放開後記住位置並恢復原狀態。
- [ ] 靜止時 16 方向追視游標；游標靠近時可呼吸、眨眼或理毛。
- [ ] 坐姿看向正左與正右時身體大小一致；連續繞行游標時沒有忽大忽小。
- [ ] 觸發摸頭時維持相近的坐姿尺寸與腳底位置，不會突然放大或上下跳動。
- [ ] 觸發舔毛時維持與待機／追視相近的尺寸，六格腳底都固定在共同基準線，不會突然放大或下沉。
- [ ] 切換 75%、100% 與 150% 時，寵物全身與透明視窗等比例縮放，不是把原尺寸圖片裁切。

## 漫遊、螢幕與 DPI

- [ ] 關閉漫遊後不再自行位移，但拖動與互動仍正常。
- [ ] 「目前螢幕」不離開當前工作區；「所有螢幕」可跨螢幕且避開工作列。
- [ ] 「所有螢幕」可直接把寵物拖過螢幕邊界；放開後完整留在游標所在螢幕，且不會被舊漫遊目標拉回。
- [ ] 快速模式或畫面短暫卡頓時不會越過目標後持續撞牆；若 250 ms 完全沒有位移，會停止本次路徑並重新選點。
- [ ] 測試單螢幕、負座標排列、不同工作列位置與 100%、125%、150%、200% DPI。
- [ ] 拔除螢幕、改解析度或 DPI 後，寵物自動回到可見工作區。

## 設定、系統匣與發佈

- [ ] 系統匣可顯示/隱藏、切換漫遊與滑鼠穿透、開啟設定、回主螢幕及退出。
- [ ] 在寵物本體按右鍵會顯示與系統匣相同的選單。
- [ ] 「所有螢幕」模式走到工作區邊界後，會從目標螢幕對應邊緣繼續，不會在原邊界踏步。
- [ ] 開啟滑鼠穿透後仍可由系統匣關閉。
- [ ] 漫遊範圍、速度、75%–150% 大小、穿透、開機啟動、最後螢幕與位置可保存。
- [ ] 破損設定或無效位置會安全復原，不使程式無法啟動。
- [ ] Release 測試通過，`win-x64` 自包含單檔可攜版在乾淨環境啟動。

## 餵食（v1.1.0 候選）

- [ ] 右鍵寵物與系統匣「餵食薯餅」均提供蘋果、紅蘿蔔、飼料三種食物。
- [ ] 餵食期間漫遊停止，拖曳、單擊、雙擊、摸頭與其他左鍵反應不能覆寫餵食序列。
- [ ] 專用寫實影格維持雙爪—食物—嘴部接觸，完成顯示「吃飽了！」並播放 HappyJump；完成後可恢復拖曳與漫遊。
- [ ] 3 秒冷卻有效；冷卻中不能重複餵食，`TotalFeedCount` 每次完成只增加一次。
- [ ] `TotalFeedCount`、`LastFedUtc`、`LastFoodType` 正確保存；schema 2 設定升級至 schema 3 且舊欄位預設正確。
- [ ] click-through 開啟時仍可從系統匣餵食。
- [ ] 75%、100%、150% 縮放及單／多螢幕下，三種寫實進食影格均完整等比例顯示，腳底不跳位且食物維持在雙爪與嘴部之間。
- [ ] 透明無標題 WPF 視窗無法被 computer-use 穩定鎖定為輸入目標；右鍵桌寵的實際視覺操作需在實機人工驗收。
