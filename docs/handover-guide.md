# 薯餅桌寵交接手冊

目前交接分支：`agent/feeding-feature`；穩定回復基準：`v1.0.0` tag/release。目前驗收版本為 `v1.1.0` 候選。

## 接手前檢查

- 取得 `v1.0.0`（餵食功能前穩定基準）及其後續提交，確認工作目錄沒有未說明修改。
- 使用 Windows 10/11、.NET 8 SDK 建置並執行完整測試（目前 110 個）。
- 閱讀 README、本手冊、維護手冊、`docs/manual-qa.md` 與 `docs/verification-report.md`。
- 確認 `pet-art/references/reference_catalog.csv` 列出全部 81 張照片，圖集與 `pet.json` 版本一致。

## 功能驗收清單

- [ ] 透明、無邊框、永遠置頂、不出現在工作列。
- [ ] 左鍵拖曳、單擊抬爪、雙擊跳躍、摸頭、游標追視。
- [ ] 目前螢幕／所有螢幕、負座標、螢幕間隙、工作列位置及 100%–200% DPI。
- [ ] 邊界不撞牆；所有螢幕漫遊能經由入口轉換。
- [ ] 75%–150% 為等比例縮放，坐姿、走路、舔毛與摸頭腳底基準一致。
- [ ] 右鍵選單與系統匣選單一致；滑鼠穿透可由系統匣恢復。
- [ ] 設定、最後位置、螢幕及開機啟動狀態可保存。
- [ ] 螢幕拔除、解析度／DPI 變更後仍完整可見。
- [ ] EXE、設定視窗及系統匣圖示均為薯餅圖片。
- [ ] 右鍵桌寵／系統匣可選「餵食薯餅」→「種子棒（薯餅實拍）」。
- [ ] 餵食期間不可拖曳或點擊覆寫；完成顯示「吃飽了！」、播放 HappyJump，統計只增加一次，3 秒冷卻後恢復拖曳與漫遊。
- [ ] 種子棒進食維持前爪—食物—嘴部接觸；左右八格步態沒有腳掌瞬移、滑動、懸空或方向切換大小跳動。
- [ ] Click-through 開啟時仍可由 tray 餵食；75%–150% 縮放與多螢幕均正常。

## 已知限制

- 實際多螢幕拖曳、不同工作列四側、長時間置頂感受仍需在使用者實機人工確認；自動測試已涵蓋座標計算與邊界邏輯。
- 可攜版搬移後，若啟用開機啟動，必須重新儲存設定以更新捷徑目標。
- 滑鼠穿透開啟時，桌寵本體不能接收右鍵或拖曳，只能透過系統匣操作。
- `v1.0.0` 不包含餵食功能；目前 `agent/feeding-feature` 是 `v1.1.0` 候選，正式發佈前保留舊版 tag/release 可回復。

## 交接資料與回復

交接時提供原始碼、`pet-art/`、測試結果、驗證報告、發佈 EXE 的 SHA-256、設定 schema、GitHub 儲存庫位置與最新版本標籤；不要提交 `%LOCALAPPDATA%\ShuBingDesktopPet\settings.json` 或 `dist/`。新版本啟動失敗時，以最後穩定 tag 重建可攜版，保留失敗版本測試輸出與設定備份。
