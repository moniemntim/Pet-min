# 薯餅桌寵使用說明

## 安裝與啟動

薯餅桌寵是 Windows 10/11 的 .NET 8 WPF 自包含單檔可攜版，不必另外安裝 .NET。解壓或複製 `dist/ShuBingDesktopPet-win-x64` 資料夾後，執行 `ShuBingDesktopPet.exe`；最終發佈的 EXE 已內含所需執行環境與角色資產。開發版則直接由 Visual Studio 或 `dotnet run` 啟動。

程式會在透明、無邊框、永遠置頂且不出現在工作列的視窗中顯示薯餅。關閉程式請使用系統匣或桌寵右鍵選單的「退出」。

## 基本操作

- 在薯餅上按住左鍵，移動超過 6 DIP 後即可拖曳；拖曳期間會暫停漫遊，放開後保存位置與螢幕。
- 單擊會抬爪，雙擊會開心跳躍。
- 游標在頭部區域左右來回移動會觸發摸頭；靜止時薯餅會依游標方向追視，靠近中心時會呼吸、眨眼或整理毛髮。
- 在薯餅本體按右鍵會開啟與系統匣相同的選單。
- 右鍵寵物或系統匣選「餵食薯餅」，再選「蘋果」、「紅蘿蔔」或「飼料」。薯餅會用雙爪拿著食物在嘴邊進食，完成後顯示「吃飽了！」並播放 HappyJump。
- 餵食期間會暫停漫遊、拖曳及其他左鍵互動；完成後恢復原本狀態。每次完成後有 3 秒冷卻，冷卻中選擇食物不會重複計數。
- 若開啟滑鼠穿透，桌寵不會接收滑鼠操作；請從系統匣關閉「滑鼠穿透」後再拖曳或互動。

## 設定

從系統匣「設定」開啟設定視窗：

- 「啟用漫遊」：開啟後會在工作區內隨機走動與停留；關閉後停在目前位置，但仍可拖曳及互動。
- 「漫遊範圍」：選擇「目前螢幕」或「所有螢幕」。所有螢幕模式會穿越虛擬桌面中的螢幕入口，並避開工作列。
- 「速度」：慢、正常、快。
- 「大小」：75%–150%，以等比例縮放完整視窗，不是裁切圖片。
- 「滑鼠穿透」：預設關閉；開啟後由系統匣恢復操作。
- 「開機啟動」：預設關閉；啟用後會在目前使用者的 Windows 啟動資料夾建立捷徑。

系統匣選單另有「顯示／隱藏」、「漫遊」、「滑鼠穿透」、「設定」、「回到主螢幕」及「退出」。

滑鼠穿透開啟時仍可從系統匣進入「餵食薯餅」；餵食期間的 overlay 不接收滑鼠事件。

## 設定與資料位置

設定會保存於：`%LOCALAPPDATA%\ShuBingDesktopPet\settings.json`。內容包含漫遊狀態、範圍、速度、大小、滑鼠穿透、開機啟動、最後位置與螢幕識別，以及 `TotalFeedCount`、`LastFedUtc`、`LastFoodType` 餵食統計。設定 schema 3 可向後讀取 schema 2，舊設定的餵食欄位會使用預設值。螢幕拔除、解析度或 DPI 改變後，程式會將寵物夾回可見工作區。

若要重設設定，先退出程式，再備份後刪除 `settings.json`，下次啟動會使用預設值（漫遊開啟、目前螢幕、正常速度、100%、穿透關閉、開機啟動關閉）。

## 疑難排解

### 找不到系統匣圖示

確認程式仍在執行；若圖示被 Windows 隱藏，請到工作列的隱藏圖示區查看。重新啟動最新版 EXE 可重新建立圖示。

### 無法拖曳

先從系統匣關閉滑鼠穿透。所有螢幕模式下，拖曳到另一螢幕後放開即可；程式會依游標所在工作區修正邊界。

### 薯餅卡在邊界或位置失效

從系統匣選「回到主螢幕」。若顯示器剛拔除或 DPI 剛變更，等待畫面設定事件完成後再操作。

### 設定沒有保存

確認程式有權限寫入 `%LOCALAPPDATA%`，並確定按下「儲存」而不是「取消」。損壞的 JSON 會被安全地退回預設值。

### 開機啟動失效

確認設定中的「開機啟動」已開啟，且可攜版資料夾未被移動；啟動捷徑指向最後一次執行的 EXE。Windows 安全性軟體或公司政策可能阻擋啟動資料夾捷徑。
