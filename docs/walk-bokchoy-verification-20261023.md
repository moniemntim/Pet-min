## 驗證範圍限制

尚未以真實滑鼠操作桌面拖曳與追視，也未在 OBS Studio 或 Twitch 網路事件下完成端到端驗收。計畫中的可攜 EXE 啟動測試涉及暫時改寫本機設定；自動核准審查拒絕該指令，只回傳 `blocked by policy`，故未執行，亦未改寫使用者設定。不可將程式化 WPF 繪製或建置成功等同上述人工驗收。

瀏覽器政策拒絕開啟本機 `file:` 預覽，只允許 HTTP(S)，因此未執行瀏覽器互動測試，也未使用替代網路方式繞過。已直接檢視最後的固定畫布對照圖片；HTML 與 GIF 可由使用者在本機開啟。
