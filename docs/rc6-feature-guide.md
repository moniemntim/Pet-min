# v1.1.0-rc.6 身形與時間設定說明

## 使用方式

從桌寵右鍵選單或系統匣開啟「設定」：

- 「寵物身形」可選「目前身形（原本）」或「修長身形」。原本走路圖完全保留；修長版只在自主漫遊走路時套用。
- 「每次吃食物時間」可設 1–20 秒，0.5 秒一格，預設 4 秒。時間內進食六格會自然循環，到期後才計數、顯示吃飽訊息並跳躍。
- 「連續走路時間」可設 2–60 秒，1 秒一格，預設 8 秒。薯餅會在同一段走路時間內持續選擇下一個目標，時間到才停下休息。

三項設定會和其他設定一樣保存至 `%LOCALAPPDATA%\ShuBingDesktopPet\settings.json`。舊設定檔缺少欄位時會使用上述預設值；未知身形值會安全退回原本身形。

## 動畫與方向

修長版使用左右各八格的獨立 256×208 RGBA 資源；可見身體寬度 246 px、高度 126–131 px，腳底最高可見像素固定在 y=170。它使用加寬畫布增加肩膀到臀部的真實長度，不是把原圖壓扁或裁切。右向列由左向列逐像素水平鏡像，因此畫面位移方向與頭部朝向一致，不會倒退走路。

選擇修長身形後，視窗會按 256×208 畫布等比例縮放；坐下、餵食與互動仍使用原本 192×208 影格並置中，所以不會被橫向拉伸。修長走路的棕毛、白毛亮度和毛髮高光以現有待機／坐下影格校色。資源缺一格、尺寸錯誤或無法讀取時，整組修長版會停用並回退到原本走路，不會在動畫途中混入兩套走路影格。

## 維護重點

- 資源位置：`Assets/Walking/LongBody/Left|Right/00.png..07.png`。
- `WalkingBodyFrameCache` 只在啟動時載入並 Freeze 16 張 256×208 圖；每次 tick 重用，不建立新影像物件。
- `MainWindow` 只在修長資源完整時使用 256 px 根畫布；切換身形或大小時保留視覺中心，原本 192 px 動作會置中顯示。
- `RoamingWalkTimer` 只在可自由走路時扣時間；餵食、反應、按住準備拖曳及拖曳期間都暫停。
- `FeedingController` 在開始餵食時鎖定該次設定時間，完成後才開始三秒冷卻。
- 修改資源後至少要重跑 `Rc6TimingAndLongBodyTests`、完整 Release 測試、透明／鏡像／腳底線檢查與實機走路觀察。
