# 1.2.0-rc.1 refresh architecture

日期：2026-10-23

這是候選版的素材與註冊說明；正式版仍為 `v1.1.0`。本次候選版包含 113 筆映射：73 筆主圖集、24 筆餵食素材（含 12 筆既有食物別名）與 16 筆修長走路素材。

## 尺度與註冊

每張生成 sheet 使用單一固定 scale，禁止逐格 fit。一般畫布為 192×208，修長走路為 256×208；非跳躍動作的 body contact baseline 為 y=170。跳躍 baseline offset 依序為 `0, 0, -18, -8, 0`。分格工具以 body alpha 與 fur alpha 分別計算 bbox，使用 premultiplied-alpha resize，只平移到共同中心與基準線，並保留透明毛尖與鬍鬚。原始 sheet 邊界接觸只在實際選用 frame 上檢查；孤立細毛會記錄，厚實 body core 或長連續區域會拒絕。

載入時共用一次毛色 palette 校正，參考色為 `181/156/133` 與 `237/234/228`；食物遮罩保護種子棒顏色。這些是生成視覺素材的推定與校正參數，不能解讀為原始照片的逐像素量測。

## 執行整合

沿用既有食物 enum、schema 7、餵食 timeline、TwitchPellet 識別值與 OBS／桌面同步協定。花椰菜餵食為六格抱食、靠近嘴部、啃咬、低頭、咀嚼與收尾序列；種子棒仍使用既有 Twitch 觸發流程。

生成素材與 QA 預覽位於 `pet-art/refresh-20261023/`，候選可攜版預期位於 `dist/ShuBingDesktopPet-refresh-20261023/`，預覽頁為 `pet-art/refresh-20261023/preview.html`。來源清單位於 `references/image-manifest.json` 與 `references/video-manifest.json`，提示詞位於 `prompts/`，前版備份位於 `before/`；它們是追溯資料，不是 runtime 資源。

## 驗證狀態

完整紀錄見 `pet-art/refresh-20261023/verification.md`，測試機器紀錄位於 `validation/`。本次已執行 Release 測試與 Windows x64 自包含發佈；候選版保留在獨立資料夾。

透明、無工作列視窗無法由目前的桌面操作工具選取，因此未宣稱完成真實滑鼠拖曳、桌面追視及 OBS Studio Window Capture 端到端操作。WPF RenderTargetBitmap 與實際 ObsCaptureWindow.RenderFrame 的測試，和上述人工操作是不同層級的驗證。Twitch 網路事件未連線實測。

素材預覽中的角色外觀與尺寸判斷屬生成素材的視覺審查；照片與影片則是實際參考來源。固定倍率、畫布、透明度、基準線及資源雜湊另有程式檢查，不能把這些檢查解讀為每個毛色斑點完全無生成差異。
