# 薯餅外觀基準

本基準由 `圖` 內 81 張原照共同整理；逐張來源、視角、姿勢、可見程度與清晰度記錄於
`pet-art/references/reference_catalog.csv`，九張完整圖板位於 `pet-art/references/reference_board_*.jpg`。

## 固定身分特徵

- 真實成年黃金鼠比例：低重心、橢圓而圓潤的軀幹，小而自然的四肢，不採人形站姿。
- 頭部與前肩為暖灰棕／淡褐色；額頭、口鼻與雙頰不得新增白色中線或虛構斑點。
- 肩後至身體中段是寬而清楚的白色環帶，腹部與胸口偏白。
- 白色背區有一塊小型棕色背斑；後半身與臀部回到棕色。左右視角需維持同一套邊界，不能逐格漂移。
- 眼睛為小而圓的亮黑色，大小符合實物；禁止卡通放大眼或額外高光圖案。
- 鼻子、腳掌與腳趾為柔和粉色；內耳半透明粉色，耳緣有短毛。
- 毛髮短而細密，輪廓可見自然毛尖；禁止塑膠、布偶或平面插畫質感。
- 不添加衣服、配件、文字、食物、地板、陰影、光暈或任何場景物件。

## 參考優先級

1. 清晰全身側面照定義頭身比例、腿長、白色環帶及臀部輪廓。
2. 正面與三分之四照定義眼距、鼻形、臉頰寬度、雙耳位置。
3. 頭頂與背面照定義背斑、白帶寬度、後半身棕色區域與尾部周圍。
4. 手持、腹面及站立照只補足腹部、腳掌、伸展時肢體比例，不作為中性姿勢比例。
5. 模糊、遮擋或局部照片僅補充動作機械與局部花紋，不覆蓋清晰照片的主外觀。

## 圖集一致性檢查

- 每格只有一隻完整薯餅，四肢數量與關節方向正確，沒有分離肢體。
- 所有非跳躍格使用相同腳底基準線；角色在 192×208 安全框內完整可見。
- 走路列左右方向明確、步態相位連續；左右兩列的身分特徵相同。
- 點擊、跳躍、摸頭、拖動與理毛列只改動姿勢，不改動毛色、眼睛大小或年齡。
- 16 個追視方向以頭、鼻、耳與眼神共同轉向，身體尺度及落腳點保持穩定。
- 最終透明邊緣沒有綠邊、白邊、硬鋸齒或半透明髒邊。
