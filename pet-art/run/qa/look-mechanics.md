# 薯餅追視動作機制

- 薯餅維持自然坐姿，兩隻後腳與臀部固定在同一基準線；16 個方向都不得平移、浮起或縮放整隻身體。
- 身體體積、胸腹寬度與頭部大小固定。每個相鄰 22.5° 方向只改變頭部轉向、鼻尖、眼神、耳朵遮擋和極輕微的上身跟隨。
- 000 向上：鼻尖抬向畫面上方，可見下巴與胸口；090 向畫面右：頭轉向右側且右側輪廓清楚；180 向下：低頭看前腳；270 向畫面左：頭轉向左側且左側輪廓清楚。
- 右半圈逐步由抬頭正面轉成右側面、低頭右側面，再到低頭正面；左半圈對稱地由低頭正面轉成左側面，再回到抬頭正面。
- 黑色眼睛是實際球狀眼睛，視線先轉，頭部再跟隨；不可新增眼白、卡通瞳孔或第二層眼睛。
- 耳朵隨頭部轉動而自然遮擋，身體棕白花紋、四肢、腳掌與毛髮不得換位或漂移。
- 動作預算：相鄰格的頭部轉角與鼻尖位移近似等量；任何一格的可見身體面積不得比相鄰格改變超過約 10%。
- 統一顯示包圍盒目標：側坐約 88–100 px 寬、120–132 px 高；正面坐姿約 82–96 px 寬、120–132 px 高；腳底基準固定在 y=168–170。這是最終 192×208 格的目標，不得沿方向逐格縮小。
